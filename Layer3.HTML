Layer 3: On and Off Ramp Applications for Tokenizing Real World Assets

Layer 3 Applications are web extensions that allow users to interact with Ethereum's' Ecosystem. Users can be individuals, businesses, banks, governments and developers. Layer 3 Applications provide the gateway for users to tokenize their real world assets or retrive them.

For example: Web 3 Application Meta Mask is a web extension programmed as a wallet. This wallet provides the gateway to interacting with Ethereum's' Layer 2 Blockchains.

Below is a list of the most promenate Layer 3 Applications.

Layer 3 Applications

  • Meta Mask = Wallet
  • Coinbase = Decentralized Exchange
  • Ondo = Real World Asset Tokenization Platform
  • Lido = Liquid Staking Derivative
  • Blast = Non-Fungible Token (NFT) Platform
  • Chainlink = Oracle Network
  • The Graph = Indexing Protocol
  • USD Coin = Stablecoin
